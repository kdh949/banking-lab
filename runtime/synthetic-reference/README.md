# Synthetic Runtime Reference

This directory contains synthetic-only Node helper modules used by local tests,
evidence generators, and the legacy `runtime/labApp.mjs` simulator.

It is not a target product area. The official staff terminal UI is the Next.js
iWorks-style integrated terminal under `apps/staff-terminal/src/app/page.tsx`
and `apps/staff-terminal/src/components/integrated-terminal.tsx`.

Do not add staff-terminal screens, mockups, design prototypes, or production
frontend code here.
