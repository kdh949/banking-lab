# FDS/AML Analytics Spring Read API Evidence

Date: 2026-06-04

## Scope

Phase 5 adds a Spring read API for the generated synthetic FDS/AML analytics artifact and routes the FDS/AML console panel through the shared API client instead of directly importing the JSON file.

Endpoint:

```text
GET /api/fds/analytics?reason=<business reason>
```

## Controls

- Requires an authenticated FDS/AML/audit/compliance role.
- Requires a business reason and returns `POLICY_REASON_REQUIRED` when omitted.
- Rejects artifacts that indicate real money, real PII, or real bank-network use.
- Requires deterministic scoring and DuckDB mart generation flags in the artifact.
- Appends `FDS_ANALYTICS_EVIDENCE_VIEW` audit events with screen `FDS-301`.
- Reads `docs/test-evidence/generated/fds-aml-analytics.json`, which is synthetic-only batch evidence generated by the Python/DuckDB analytics module.

## Synthetic Boundary

This API exposes only generated synthetic analytics evidence. It does not call real payment networks, real financial institution APIs, KYC providers, or external customer data sources.
